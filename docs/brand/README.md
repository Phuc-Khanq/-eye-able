# [eye]able brand files

The mark is an open eye inside a camera viewfinder.

| File | Use it for |
| --- | --- |
| `eyeable-icon.svg` | The app icon: the sage mark on a dark rounded square. Favicons, shortcuts, social cards. |
| `eyeable-mark-sage.svg` | The mark alone, sage, for dark backgrounds. |
| `eyeable-mark-ink.svg` | The mark alone, dark ink, for light backgrounds. |
| `eyeable.ico` | Windows icon (16 to 256 px). The installer gives the EYEable shortcut this icon. |
| `png/` | PNG exports: the icon at 16 to 1024 px, the marks at 512 and 1024 px. |

Colors: ink `#0B0C0D`, sage `#B7C59F`, dark ink `#1E2418`.

Write the name as **[eye]able** in text. File and folder names spell it `EYEable` or `eyeable`, because square brackets cause trouble in Windows paths and scripts.

README pictures and website screenshots are in [`../media`](../media).
